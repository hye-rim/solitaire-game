# 솔리테어 ♥️

윈도우 기본 게임으로 익숙한 클론다이크 솔리테어. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `seeds.js` + `game.js`)입니다.

- 52장. 7개 열에 1장, 2장 … 7장씩 깔고 각 열의 맨 위 한 장만 앞면. 나머지 24장은 더미(왼쪽 위)
- 열 위에는 **색이 다르고 숫자가 1 작은** 카드를 올린다 (빨강 7 위에 검정 6). 앞면 카드는 묶음으로 옮긴다. 빈 열에는 K만
- 오른쪽 위 4칸(♠♥♣♦)에 **같은 무늬로 A→K** 순서로 쌓는다. 4무늬를 모두 K까지 쌓으면 승리
- 더미를 누르면 카드를 넘겨 웨이스트에 펼친다. 더미가 비면 눌러서 다시 뒤집는다(무제한). **1장씩(쉬움)** / **3장씩(보통)** 모드
- 점수(윈도우 방식): 웨이스트→열 +5 · →파운데이션 +10 · 열→파운데이션 +10 · 뒷면 뒤집기 +5 · 파운데이션→열 -15 · 더미 다시 넘기기 -100(1장)/-20(3장). 이기면 시간 보너스(700000 ÷ 초, 최대 23,333)
- **풀 수 있는 판만 나온다**: `tools/find-seeds.js` 가 한 장씩 넘기기 기준으로 끝까지 풀리는 판을 찾아 `seeds.js`(300개)에 넣어 둔다. (3장씩 모드는 같은 판을 쓰지만 풀린다는 보장은 한 장씩 기준)
- 카드를 누르면 가장 알맞은 곳(파운데이션 > 뒷면이 드러나는 열 > 다른 열)으로 알아서 옮기고, 끌어서 놓아도 된다. 되돌리기 · 힌트 · 자동 마무리(뒷면 카드와 더미가 없을 때) · 이어하기(자동 저장)
- 최고 점수는 모드별 `solitaireBest1` · `solitaireBest3`, 로비 표시용은 둘 중 큰 값 `solitaireBest`
- PC: Z 되돌리기 · H 힌트 · D/Space 더미 · A 자동 마무리 · M 소리 · P 일시정지

규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력은 `game.js`. 스파이더 카드의 카드 그리기·끌기·저장 코드를 바탕으로 했다.

## 풀 수 있는 판 목록 다시 만들기
```bash
node tools/find-seeds.js 300 150000   # 개수, 탐색 한도 → seeds.js
node tools/verify.js 60 50000         # 찾은 풀이를 실제 규칙으로 재생해 검증
```
